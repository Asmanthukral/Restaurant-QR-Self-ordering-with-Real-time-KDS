# Restaurant QR Self-Ordering with Real-time KDS

A full-stack touchless dining web application designed to streamline the ordering process in restaurants through QR codes, integrated with a real-time Kitchen Display System (KDS) and multi-channel logging.

## 🚀 Features
- **QR-Based Self-Ordering**: Customers can scan a table QR code to view the menu and add items directly to their cart.
- **Real-time Kitchen Display System (KDS)**: Powered by Firebase Firestore for instant order syncing between customers and kitchen staff.
- **Local MySQL Order Logging**: Secure backend order history tracking using Node.js, Express, and MySQL.
- **WhatsApp Integration**: Automated direct messaging to the restaurant owner/kitchen with complete order details and bill breakdowns.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6 Modules)
- **Backend**: Node.js, Express.js
- **Database**: MySQL (Local Backend) & Firebase Firestore (Real-time KDS)
- **APIs**: WhatsApp Cloud/Web API integration
